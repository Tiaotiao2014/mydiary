# MyDiary 玻璃拟态双主题 UI 设计方案

> 版本：v1.0 ｜ 适用产品：MyDiary（纯本地日记软件，Electron 31 + Vue 3）
> 设计定位：**一套结构，两种气质** —— 浅色治愈系 × 深色黑客帝国
> 配套交付：`MyDiary-界面模板.html`（可直接双击打开的交互式高保真模板）

---

## 1. 设计理念

### 1.1 一句话概括

> 白天，它是一间洒满阳光的奶油色书房；夜里，它是一块闪烁着荧光绿的终端屏幕。
> 玻璃是同一块玻璃，只是背后的光变了。

### 1.2 核心理念：Glassmorphism 作为「层」的语言

本方案的毛玻璃不是装饰贴纸，而是**信息分层语言**：

| 层级 | 角色 | 玻璃强度 |
|------|------|----------|
| L0 背景层 | 柔光色块（浅色）/ 代码雨 + 扫描线（深色） | — |
| L1 结构层 | 侧边栏、顶栏、页面容器 | 强玻璃（模糊 20px+） |
| L2 内容层 | 卡片、表格、工具栏 | 标准玻璃（模糊 16px） |
| L3 浮层层 | 弹窗、Toast、下拉菜单 | 重玻璃（模糊 24px + 更高不透明度） |

关键守则：**任何玻璃层之下必须有可折射的「光」**。浅色主题用 3–4 个大尺寸柔光色块（杏橘 / 鼠尾草 / 雾蓝）缓慢漂移；深色主题用低亮度代码雨与扫描线。光在动，玻璃才「活」。

### 1.3 双主题哲学

- **浅色 · 治愈系「暖白书房」**：低饱和暖白与奶油底、鼠尾草绿主色、杏橘点缀；大圆角、柔阴影、充裕留白。目标情绪：安全、松弛、适合书写私密心事。
- **深色 · 黑客帝国「终端矩阵」**：纯黑底、荧光绿 `#00FF41` 系主色、等宽字体细节、代码雨背景、扫描线纹理；小圆角、细描边、幽绿光晕。目标情绪：专注、私密、极客掌控感。
- **统一骨架**：两套主题共享同一套间距栅格、字号阶梯、组件结构尺寸与交互逻辑，仅替换「皮肤变量」。用户切主题时肌肉记忆零成本。

### 1.4 易用性四支柱

1. **信息架构符合惯例**：左侧导航 + 主内容区的桌面应用经典结构，与 VS Code / Obsidian 等用户已有心智模型一致。
2. **视觉层级 = 玻璃层级**：越重要、越临时的内容，玻璃越「实」、阴影/光晕越强。
3. **8pt 间距系统**：所有尺寸对齐 4px 基准网格，节奏稳定。
4. **无障碍底线**：正文对比度 ≥ 4.5:1（WCAG AA），焦点可见，动效可关。

**语义色（深色）**

| 语义 | 文字/图标 | 背景淡色 |
|------|-----------|----------|
| Success | `#37FF8B` | `rgba(55,255,139,.12)` |
| Warning | `#FFD24D` | `rgba(255,210,77,.12)` |
| Error | `#FF6057` | `rgba(255,96,87,.12)` |
| Info | `#57C7FF` | `rgba(87,199,255,.12)` |

**背景氛围（L0）**：
- **代码雨**：Canvas 绘制，字符集 `ｱｲｳｴｵ ﾊﾋﾌﾍﾎ 0 1` + 片假名，列宽 14–18px，整体透明度 ≤ 0.35，头部字符高亮 `#B8FFC8`。
- **扫描线**：`repeating-linear-gradient`，1px 线 / 3px 间隔，透明度 0.03–0.05，覆盖全屏但 pointer-events:none。
- **克制原则**：代码雨与扫描线**只存在于 L0 背景层**，禁止叠加在正文阅读区正下方（局部玻璃的不透明度需足以保证可读性）；`prefers-reduced-motion` 时雨幕静止。

### 2.3 对比度合规表（WCAG AA）

| 组合 | 浅色 | 深色 |
|------|------|------|
| 正文 / 底色 | 10.9:1 ✓ | 15.1:1 ✓ |
| 次文本 / 底色 | 5.4:1 ✓ | 9.3:1 ✓ |
| 主按钮字 / 底 | 5.05:1 ✓ | 13.9:1 ✓ |
| 品牌色文字 / 底色 | `#4A7866` 5.0:1 ✓ | `#00FF41` 15.4:1 ✓ |
| 错误文字 / 底色 | 5.3:1 ✓ | 6.8:1 ✓ |

> 注意：浅色 `brand-500 #6B9A86` 与杏橘 `accent #E9B48E` 仅作装饰/描边，**不得**用于正文文字色。

## 3. 字体与排版规范

### 3.1 字体家族

| 用途 | 字体栈 |
|------|--------|
| 界面正文 | `"Noto Sans SC", "PingFang SC", "Microsoft YaHei UI", system-ui, sans-serif` |
| 数字 / 日期 / 代码 / 深色主题标签 | `"JetBrains Mono", "Cascadia Mono", Consolas, monospace` |

- 深色主题刻意在**日期、统计数字、状态标签**上启用等宽字体，强化终端气质；浅色主题仅代码块使用等宽。
- 全部使用系统可回退字体栈，**零外部字体依赖**（本地离线应用约束）。

### 3.2 字号阶梯（两主题共用）

| Token | 尺寸 / 行高 | 字重 | 用途 |
|-------|------------|------|------|
| `display` | 28 / 36px | 700 | 统计大数字、空状态标题 |
| `h1` | 22 / 30px | 600 | 页面标题 |
| `h2` | 18 / 26px | 600 | 卡片标题、弹窗标题 |
| `h3` | 16 / 24px | 600 | 区块标题 |
| `body` | 14 / 22px | 400 | 正文（编辑器正文 16/28） |
| `body-lg` | 16 / 28px | 400 | 编辑器正文（书写场景放宽） |
| `sm` | 13 / 20px | 400 | 辅助说明、表格内容 |
| `xs` | 12 / 18px | 500 | 标签、徽章、时间戳 |

### 3.3 排版规则

- 标题字距 0；深色主题 `h1/h2` 增加 `letter-spacing: .02em` + 字重 600，避免荧光绿在黑底上视觉发「糊」。
- 正文最大行宽 **68ch**（编辑器与阅读态），列表卡片摘要 2 行截断。
- 段间距 = 1.5 × 行高；列表项间距见间距系统。

## 4. 间距、圆角与栅格

### 4.1 间距系统（4px 基准 / 8pt 节奏）

| Token | 值 | 典型用途 |
|-------|----|----------|
| `space-1` | 4px | 图标与文字间隙 |
| `space-2` | 8px | 紧凑内边距（标签、表格单元格） |
| `space-3` | 12px | 输入框内边距、列表项间距 |
| `space-4` | 16px | 卡片内边距（默认） |
| `space-5` | 20px | 弹窗内边距 |
| `space-6` | 24px | 分组间距、卡片间距 |
| `space-8` | 32px | 页面区块间距 |
| `space-12` | 48px | 页面外边距（桌面） |

### 4.2 圆角系统（主题差异化）

| Token | 值 | 浅色默认 | 深色默认 |
|-------|----|----------|----------|
| `radius-xs` | 6px | 标签 | 标签 |
| `radius-sm` | 10px | 小按钮 | **按钮/输入框统一** |
| `radius-md` | 14px | 按钮/输入框 | 卡片 |
| `radius-lg` | 20px | 卡片 | 弹窗 |
| `radius-xl` | 28px | 弹窗/大容器 | —（深色不使用） |
| `radius-full` | 999px | 胶囊按钮、头像 | 胶囊按钮 |

> 圆角是两主题「性格差异」的主要载体：浅色圆润亲和（默认 lg），深色硬朗锐利（默认 sm–md），但**表单控件两主题统一 sm**，避免肌肉记忆错位。

### 4.3 栅格

- **桌面主框架**：`240px（侧栏）+ 1fr（内容）`，内容区最大 1200px 居中，左右留白 ≥ 32px。
- **日记列表网格**：`repeat(auto-fill, minmax(300px, 1fr))`，间距 24px。
- **编辑器**：单栏居中，正文容器 720px（约 68ch）。
- **断点**：≥1280 桌面全功能 / 1024–1279 紧凑 / <1024 侧栏折叠为图标列（64px）。

## 5. 玻璃材质规范（核心）

| 属性 | 浅色 | 深色 |
|------|------|------|
| 模糊 | `backdrop-filter: blur(18px) saturate(140%)` | `blur(18px) saturate(120%)` |
| 玻璃底色 | `rgba(255,253,248,.62)` | `rgba(2,16,7,.60)` |
| 内描边（顶高光） | `inset 0 1px 0 rgba(255,255,255,.65)` | `inset 0 1px 0 rgba(0,255,65,.10)` |
| 外描边 | `1px solid rgba(139,120,98,.14)` | `1px solid rgba(0,255,65,.22)` |
| 阴影 | `0 8px 24px rgba(120,95,70,.10)` | `0 8px 24px rgba(0,0,0,.5), 0 0 16px rgba(0,255,65,.06)` |
| 悬停增强 | 阴影加深 + 玻璃透明度 -5% | 描边亮度 +8% + 微光晕 |

- 弹窗 / Toast 的玻璃不透明度提高至 0.82，模糊 24px，保证临 时内容的可读性优先。
- **性能红线**：同屏 `backdrop-filter` 元素 ≤ 30 个；列表滚动容器内的长列表项使用不透明 `surface-solid`（表格、下拉菜单即为补偿手段）。

## 6. 核心组件清单与状态矩阵

### 6.1 按钮 Button

| 变体 | 浅色 | 深色 | 尺寸 |
|------|------|------|------|
| Primary | 实心 `brand-600`，白字 | 实心 `#00FF41`，黑字 | 高 40 / 36 / 32（lg/md/sm） |
| Secondary | 玻璃底 + `border-soft` | 玻璃底 + 绿描边 | 同上 |
| Ghost | 透明底，悬停出 tint | 透明底，悬停出绿 tint | 同上 |
| Danger | 实心 `#B3402F` | 实心 `#FF6057` 黑字 | 同上 |
| Icon | 36×36 圆角 `radius-sm` | 同左 | 仅一档 |

状态：

| 状态 | 表现（两主题通用逻辑） |
|------|------------------------|
| Default | 见上表 |
| Hover | Primary：亮度 -8% / +8%，上浮 1px，光晕出现；Secondary/Ghost：出现 tint 底 |
| Active | 下压 1px，光晕收散 |
| Focus-visible | 2px 焦点环（浅 `#4A7866` / 深 `#00FF41`）+ 2px 偏移，**不用鼠标悬停样式替代** |
| Disabled | `opacity:.45`，`cursor:not-allowed`，无阴影光晕 |
| Loading | 左侧 16px 旋转描边圈，文字保留，禁止重复点击 |

### 6.2 输入框 Input / Textarea

- 高 40px，内边距 `space-3`，圆角 `radius-sm`（两主题统一）。
- 底色：浅色 `bg-deep`；深色 `rgba(0,30,12,.4)`。
- 状态：默认描边透明 → 聚焦 2px 品牌描边 + 品牌 tint 外光晕（浅暖绿 / 深荧光绿）→ 错误 2px 语义红 + 下方 12px 错误文案 → 禁用 45% 透明度。
- Search 变体：左侧放大镜图标，右侧清除按钮（有内容时出现）。
- Textarea：编辑器正文区无描边透明底，滚动 8px。

### 6.3 卡片 Card

- 日记卡：玻璃底 + `radius-lg`（深 `radius-md`）、内边距 16px；含日期（等宽字体）、标题、2 行摘要、标签行、悬停上浮 2px + 阴影/光晕增强。
- 统计卡：同结构，主数字用 `display` 级等宽字。
- 选中态：品牌 tint 底 + 2px 品牌描边。

### 6.4 导航 Navigation（左侧栏）

- 240px 宽玻璃强板，分组：**主导航**（今日 / 全部日记 / 日历 / 统计）·**库**（回收站）·**通用**（设置）。
- 项高 40px，圆角 `radius-sm`，选中 = tint 底 + 左侧 3px 品牌指示条 + 图标着色；悬停 = 8% tint。
- 顶部：Logo + 「新建日记」Primary 胶囊按钮；底部：主题切换器 + 锁定按钮 + 存储状态。
- 折叠态 64px 仅图标，`title` 提示。

### 6.5 弹窗 Modal

- 遮罩：浅 `rgba(60,50,40,.35)` / 深 `rgba(0,8,2,.7)` + 8px 模糊。
- 面板：重玻璃 0.82 / blur 24px，圆角浅 `radius-xl` / 深 `radius-lg`，宽 480px（表单）/ 640px（确认含列表）。
- 交互：`Esc` 关闭、点击遮罩关闭（表单未提交变更时不关，需二次确认）、焦点圈定（Tab 循环）、打开时焦点移至首个控件、关闭后焦点还原。
- 入场 200ms 缩放 0.96→1 + 淡入；`prefers-reduced-motion` 时仅淡入。

### 6.6 表格 Table（回收站 / 管理场景）

- 头行：不透明 `surface-solid`，`text-2` 13px 大写字距 0.05em。
- 行高 48px，斑马纹 3% tint，悬停行 6% tint，行选中品牌 tint + 左指示条。
- 空状态：居中插图 + 主文案 + Ghost 按钮。

### 6.7 其他组件（简表）

| 组件 | 规格要点 |
|------|----------|
| Tag 标签 | 高 24px 胶囊，tint 底 + 语义深色文字，最大 8 字溢出省略 |
| Switch 开关 | 40×22，开 = 品牌实心，焦点环同按钮 |
| Toast | 右下角浮出，重玻璃，含语义图标，4s 自动消失，可悬停暂停 |
| Tooltip | 深色玻璃小卡，延迟 400ms 出现 |
| 空状态 | display 标题 + 说明 + 行动按钮 |

## 8. 主题切换交互逻辑

### 8.1 状态模型

```
用户设置 userTheme: "light" | "dark" | "system"   （持久化：config.json / localStorage）
生效主题 activeTheme = system ? matchMedia('(prefers-color-scheme: dark)') : userTheme
DOM 呈现: <html data-theme="light|dark">
```

### 8.2 完整流程

1. **防闪烁（FOUC）**：`index.html` 的 `<head>` 内、CSS 加载前执行内联脚本：读 `localStorage('mydiary-theme')`，无记录则取 `prefers-color-scheme`，立即写 `data-theme`。
2. **首次访问**：默认 `system`。
3. **手动切换**：侧栏底部切换器（浅色=太阳 / 深色=月亮）。设置页提供三选一分段控件（浅 / 深 / 系统）。
4. **系统联动**：`system` 模式下监听 `matchMedia` 的 `change` 事件实时跟随；Electron 环境可改用 `nativeTheme` 事件。
5. **过渡动效**：切换时给 `<html>` 临时挂 `.theme-transition` 类，全局 `background/color/border` 350ms 过渡，450ms 后移除（避免日常样式都被过渡拖慢）。
6. **进阶彩蛋（可选）**：从切换按钮位置以 `clip-path: circle()` 扩散的「主题涟漪」揭示，600ms；`prefers-reduced-motion` 时降级为淡入淡出。
7. **动效豁免**：`prefers-reduced-motion: reduce` 时，色块漂移、代码雨落速、涟漪全部停用/静止。
8. **无障碍**：切换按钮 `aria-pressed` + `aria-label="切换到深色主题"`；快捷键 `Ctrl/Cmd+Shift+L`。
9. **切换瞬间**：深色主题代码雨 Canvas 在主题切换时才创建、离开时销毁，避免常驻耗电；扫描线为纯 CSS，随主题显隐。
10. **meta 联动**：同步更新 `<meta name="theme-color">`（浅 `#F6F1E9` / 深 `#000000`）。

## 9. 无障碍与可读性

- 全部正文/控件文字对比度 ≥ 4.5:1（见 2.3 合规表）；大字号（≥24px）装饰性文字允许 3:1。
- 焦点环：所有可交互元素 `:focus-visible` 2px 品牌色实环 + 2px 偏移，深色主题附荧光光晕。
- 可点击目标 ≥ 40×40px（图标按钮 36px + 4px 隐形热区）。
- 键盘路径：导航 Tab 顺序 = 视觉顺序；弹窗焦点圈定 + `Esc` 关闭 + 焦点还原；侧栏支持方向键导航。
- 屏幕阅读器：图标按钮全部带 `aria-label`；主题切换 `aria-pressed`；Toast `role="status"`；弹窗 `role="dialog" aria-modal`。
- 动效敏感：色块漂移 / 代码雨 / 涟漪在 `prefers-reduced-motion` 下一律静止。
- 文字缩放：布局基于 rem/流式，200% 缩放不破版。
